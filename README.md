# Booking.com UI/UX Design Project

## Overview
This project focuses on redesigning and prototyping a hotel booking user interface inspired by Booking.com. The project follows the UI/UX design process, starting with wireframes and progressing through low-fidelity and high-fidelity prototypes.

## Project Objectives
- Understand the hotel booking user journey.
- Design a user-friendly booking interface.
- Organize screen layouts and navigation.
- Develop wireframes and interactive prototypes.
- Improve usability and visual consistency.

## Design Process
1. Wireframing
2. Low-Fidelity Design
3. Low-Fidelity Prototyping
4. High-Fidelity Design
5. High-Fidelity Prototyping

## Screens
The project consists of 10 screens:
- Home Page
- Search & Date Selection
- Search Results
- Filter & Sort
- Hotel Details
- Room Selection
- Guest Details
- Payment Page
- Booking Review
- Booking Confirmation
